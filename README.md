# Job Search Assistant

Персональный ассистент для помощи в поиске работы. Работает по требованию: запустил → выполнил цикл →
завершился. Работает через браузерную автоматизацию (Playwright + Chromium):

- Помогает с оценкой вакансий
- Занимается подбором вакансий релевантных профилю пользователя
- Создаёт сопроводительные письма с помощью LLM (Decision && Generation)
- Генерирует и отправляет отчёты и уведомлений на email
- Предоставляет удобный интерфейс пользователя в котором можно работать с отчётами и анализировать метрики

## Быстрый старт

Скрипты `run.bat` (Windows) и `run.sh` (Git Bash / WSL / Linux / macOS) — это обёртки, при первом запуске сами создают
виртуальное окружение `.venv`, ставят зависимости и Chromium, ручная установка зависимостей нужна только для отладки или
нестандартного окружения.

1. Скопировать `config.local.example.yaml` в `config.local.yaml` и заполнить необходимую инфомацию о своём профиле и
   параметрах запроса
2. Запустить CLI Агента
    ```bash
    py run.py
    ```
   При первом запуске браузер откроется для ручного входа на сайт для поиска работы на котором нужно будет
   авторизоваться, после чего сессия сохранится в `data/state.json`.
3. Для работы с отчётами и мониторинга метрик
    1. Активируйте в терминале виртуальное окружение
       ```bash
       .venv\Scripts\activate
       ```
    2. Запустите веб-сервер
        ```bash
        pip install -r requirements-web.txt
        uvicorn web.main:app --reload
        ```

> [!NOTE]
> По умолчанию канал поиска hh.ru, это поведение можно переопределить в локальном конфиге `config.local.yaml`.
> Для получения подробной справки по CLI введите команду `py run.py --help`, полная документация по настройке окружения
находится в [configuration.md](docs/configuration.md).

## Как это работает

Агент помогает искать работу на сайте компании, поиск осуществляется через браузер: находит вакансии, оценивает их
соответствие профилю, готовит сопроводительное письмо и отправляет отклик. После завершения работы агента пользователь
видит на веб-странице приложения, что отправлено, что пропущено, что требует ручного действия и почему.

Агент работает по требованию, не круглосуточно. Капчу не обходит, API сайта не использует, данные
пользователя хранит локально.

## Ограничения

- Капча не обходится, API hh.ru не используется.
- Отправка откликов автоматизирована: используйте на свой риск и соблюдайте правила hh.ru.
- Сессия и переписка хранятся локально. Наружу уходят только запросы к LLM-провайдеру.
