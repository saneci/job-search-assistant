# Job Search Assistant

Персональный ассистент для поиска работы, который отсеивает нерелевантное и оставляет только то, что стоит вашего
внимания. Работает по требованию: запустил → выполнил цикл → завершился. Поиск идёт по нескольким каналам, а не только
по одной площадке.

Через браузерную автоматизацию (Playwright + Chromium) сервис:

- Оценивает вакансии и подбирает релевантные вашему профилю
- Генерирует сопроводительные письма с помощью LLM (Decision && Generation)
- Формирует и отправляет отчёты и уведомления на email
- Предоставляет веб-интерфейс для работы с отчётами и анализа метрик

## Зачем этот сервис

Это не очередной инструмент для спама откликами. Это персональный ассистент для точечного, интеллектуального
отбора только тех вакансий, которые действительно релевантны вашему профилю.

Вместо сотни откликов на всё подряд - небольшое число целевых откликов. Вы перестаёте тратить время на фильтрацию
огромного объёма нерелевантной информации и снижаете когнитивную нагрузку: сервис сам отсеивает шум и оставляет то, что
стоит вашего внимания.

Сопроводительные письма генерируются в грамотной, лаконичной форме: кратко передают ваш опыт и раскрывают для
работодателя пользу, которую вы можете принести. Это выгодно обеим сторонам - соискатель тратит меньше времени и сил,
нанимающая сторона получает более осмысленные отклики вместо потока шаблонных.

Данные обрабатываются в соответствии с законодательством о защите персональных данных. Ни email, ни имя, ни фамилия, ни
другие персональные данные не раскрываются. Даже в диагностических целях данные маскируются.

## Быстрый старт

Скрипты `run.bat` (Windows) и `run.sh` (Git Bash / WSL / Linux / macOS) - это обёртки, при первом запуске сами создают
виртуальное окружение `.venv`, ставят зависимости и Chromium, ручная установка зависимостей нужна только для отладки или
нестандартного окружения. Представленные ниже команды - для Bash-терминала.

1. Скопировать `config.local.example.yaml` в `config.local.yaml` и заполнить название резюме, поисковые запросы и
   подпись письма
2. Скопировать `.env.example` в `.env` и заполнить
3. Запустить CLI Агента
    ```bash
    ./run.sh
    ```
   При первом запуске браузер откроется для ручного входа на сайт для поиска работы на котором нужно будет
   авторизоваться, после чего сессия сохранится в каталоге `data`.
4. Для работы с отчётами и мониторинга метрик выполнить шаги
    1. Активировать в терминале виртуальное окружение (выполняется один раз)
       ```bash
        ./.venv/Scripts/activate
       ```
    2. Установить необходимые зависимости (выполняется один раз)
        ```bash
        ./.venv/Scripts/python.exe -m pip install -r requirements-web.txt
        ```
    3. Запустить веб-сервер
       ```bash
       ./.venv/Scripts/uvicorn.exe web.main:app --reload 
       ```

> [!NOTE]
> По умолчанию канал поиска hh.ru, это поведение можно переопределить в локальном конфиге `config.local.yaml`
> или опцией на один запуск: `./run.sh --channel habr` (псевдоним `--ch`).
> Для получения подробной справки по CLI введите команду `./run.sh --help`, полная документация по настройке окружения
находится в [configuration.md](docs/tutorials/configuration.md).

## Как это работает

Агент помогает искать работу на сайте компании, поиск осуществляется через браузер: находит вакансии, оценивает их
соответствие профилю, готовит сопроводительное письмо и отправляет отклик. После завершения работы агента пользователь
видит на веб-странице приложения, что отправлено, что пропущено, что требует ручного действия и почему.

Агент работает по требованию, не круглосуточно. Капчу не обходит, API сайта не использует, данные
пользователя хранит локально.

## Тесты

1. Установить зависимости
    ```bash
    ./.venv/Scripts/pip.exe install -r requirements-dev.txt
    ```
2. Запусить тесты
    ```bash
    ./.venv/Scripts/pytest.exe -q
    ```

Логика фильтров отчёта проверяется через Node (если он установлен): `pytest` вызывает
`node --test tests/js/filters.test.mjs` и пропускает проверку, когда Node нет в `PATH`.

## Ограничения

- Капча не обходится, API hh.ru не используется.
- Отправка откликов автоматизирована: используйте на свой риск и соблюдайте правила hh.ru.
- Сессия и переписка хранятся локально. Наружу уходят только запросы к LLM-провайдеру.
