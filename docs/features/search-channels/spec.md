# Feature: Каналы поиска работы

## Status

`IN_PROGRESS`

> [!NOTE]
> Первым работает hh.ru, вторым добавлен career.habr.com. Живой прогон на Habr ещё не выполнен.

## Goal

Искать вакансии на нескольких площадках, а не только на hh.ru: один цикл «оценка → письмо → отклик → отчёт»
работает для любого подключённого сайта, поэтому вакансии, опубликованные мимо hh.ru, не теряются.

## Requirements

### Functional requirements

1. Канал выбирается настройкой `search.channel`: `hh` (по умолчанию) или `habr`. Один запуск работает
   с одним каналом.
2. Правила поиска зависят от канала. На hh.ru вакансии ищутся по сохранённым запросам и региону.
   На career.habr.com поиск по запросам есть, но на текущем этапе развития проекта принято решение реализовать
   поиск по подходящим: агент читает ленту «Подходящие», а глубину ограничивает `search.pages_limit`.
3. Всё, что не зависит от сайта, работает одинаково: оценка LLM-Decision, письмо LLM-Generation, проверки письма,
   лимиты, паузы, дедупликация и дневной отчёт.
4. У каналов раздельные сессии и браузерные профили: вход на один сайт не сбрасывает вход на другой.
   Ручной вход `py run.py --login` открывает сайт выбранного канала.
5. Капча не обходится. Агент ждёт ручного решения, отправляет одно письмо о капче с названием сайта
   и останавливает запуск, если капчу не решили.
6. Отклик на Habr состоит из двух действий: кнопка создаёт отклик, письмо добавляется к нему отдельно.
   Письмо готово до первого клика, иначе отклик останется без письма. Без подтверждения сайта отклик
   не считается отправленным.
7. Вакансию с отметкой «Вы откликнулись» агент не открывает: в отчёте она получает статус `sent`
   с причиной «отклик уже отправлен», а лимит откликов не расходуется.
8. Отклик, который уходит на сайте компании, не поддерживается: вакансия пропускается с причиной.
9. Подъём резюме есть только на hh.ru, на Habr этот шаг не выполняется.
10. `--retry` идёт по ссылкам из отчётов и определяет канал записи по ссылке. Записи, которые не относятся
    к выбранному каналу, пропускаются с понятным сообщением.
11. У каждой записи отчёта есть источник: `hh` или `habr`. Записи старых отчётов без источника
    показываются отдельно. Фильтр отчёта и метрики учитывают источник.

### Limitations

- Селекторы career.habr.com проверены юнит-тестами, живой прогон на сайте нужен отдельно.
- hCaptcha рисуется только в постоянном профиле Chrome, поэтому вход на Habr возможен только вручную.
- Каналы не смешиваются: за один запуск обрабатывается один сайт. Смешанный запуск отложен.
- Отклики через внешнюю форму на стороне компании не отправляются.
- На Habr нет поиска по запросам: набор вакансий определяет сам сайт.

## Acceptance Criteria

- [x] Запуск без `search.channel` работает как раньше, на hh.ru
- [x] `search.channel: habr` читает ленту «Подходящие» без запросов и региона
- [x] Сессии и браузерные профили каналов не пересекаются
- [x] Карточка «Вы откликнулись» не открывается, в отчёте это `sent` с причиной
- [x] У записи отчёта есть `channel`, фильтр отчёта и метрики различают источники
- [x] Письмо о капче для Habr называет сайт
- [x] `--retry` пропускает записи другого канала
- [x] Подъём резюме не выполняется на Habr
- [ ] Отклик на career.habr.com подтверждается сайтом в живом прогоне
- [ ] Отклик с письмом на career.habr.com доходит до адресата
