# Feature: Поиск и оценка вакансий

## Status

`IN_PROGRESS`

## Goal

Находить подходящие вакансии по разным каналам размещения вакансий и не расходовать лимит откликов на неподходящие.

## Requirements

### Functional requirements

1. Запуск одной командой. При первом запуске пользователь входит в аккаунт вручную, далее сессия
   восстанавливается сама.
2. Резюме поднимается в поиске не чаще заданного интервала.
3. Поиск идёт по сохранённым запросам и фильтрам. Агент проходит всю доступную выдачу или столько
   страниц, сколько разрешено настройкой.
4. Вакансии из прошлых запусков и дубликаты выдачи повторно не обрабатываются.
5. Стоп-слова в названии и компании-исключения отсеиваются без LLM.
6. Агент читает описание вакансии. Decision оценивает соответствие профилю. Отклик возможен только
   при вероятности выше порога.
7. Тесты, анкеты, внешние формы, недоступный отклик и капча автоматически не проходятся: вакансия
   откладывается с понятной причиной.
8. При капче агент ждёт ручного решения и отправляет уведомление. Если решить не удалось, запуск
   останавливается.
