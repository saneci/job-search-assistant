# Feature: Отчёт об обработанных вакансиях

## Status

DONE

## Goal

По отчёту понимать результат запуска без чтения логов.

## Requirements

### Functional requirements

1. В консоли печатается краткий итог: сколько обработано, отправлено, пропущено, отложено, ошибок.
2. Дневной отчёт `data/report/<дата>.json` не удаляется. Одна запись на URL хранится в одном
   экземпляре и при обновлении переносится в отчёт текущей даты. Дата создания записи при этом
   не меняется.
3. Технический журнал `logs/<дата>.jsonl` хранит события и причины. Текст письма, профиль и контакты
   в него не попадают. Срок хранения журналов ограничен.
4. Отчёт и уведомления о капче могут отправляться на email.

#### Поля дневного отчёта:

| Объект   | Поле                   | Смысл                           | Логика работы                                      | Реализован |
|----------|------------------------|---------------------------------|----------------------------------------------------|------------|
| Отчёт    | `date`                 | дата, за которую собран отчёт   |                                                    | да         |
| Отчёт    | `updated_at`           | время последнего обновления     | обновляется при каждом сохранении                  | да         |
| Отчёт    | `summary`              | количество вакансий по статусам |                                                    | да         |
| Вакансия | `vacancies.profile`    | резюме для откликов             | pipeline.resume.name                               | да         |
| Вакансия | `vacancies.url`        | ссылка, название, компания      |                                                    | да         |
| Вакансия | `vacancies.title`      | ссылка, название, компания      |                                                    | да         |
| Вакансия | `vacancies.company`    | ссылка, название, компания      |                                                    | да         |
| Вакансия | `vacancies.status`     | текущий статус                  |                                                    | да         |
| Вакансия | `vacancies.attempts`   | сколько раз обрабатывали        |                                                    | да         |
| Вакансия | `vacancies.created_at` | дата обработки вакансии         | не меняется никогда                                | да         |
| Вакансия | `vacancies.updated_at` | время последнего изменения      | обновляется при каждом изменении                   | да         |
| Вакансия | `vacancies.reason`     | причина статуса                 |                                                    | да         |

#### Статусы вакансии:

| Статус     | Значение                                                        |
|------------|-----------------------------------------------------------------|
| `sent`     | отклик отправлен или уже был отправлен ранее                    |
| `skipped`  | вакансия не подходит, приглашение или нет доступа               |
| `queued`   | нужен ручной отклик: тест, анкета, форма, капча, письмо, ссылки |
| `excluded` | стоп-слово в названии или компания-исключение                   |
| `error`    | сбой обработки                                                  |
| `rejected` | работодатель отказал. Терминальный статус                       |
| `offer`    | оффер. Терминальный статус, только из `sent`                    |
