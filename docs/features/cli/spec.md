# Feature: Командная строка

## Status

`DONE`

## Goal

Дать пользователю единый понятный вход в приложение: обычный запуск, вход в аккаунт, повтор, выбор канала и служебные
команды. Справка объясняет каждую опцию без чтения исходников.

## Requirements

### Functional requirements

1. Запуск — через скрипты `run.bat` (Windows) или `./run.sh` (Bash): они готовят окружение и передают опции в `run.py`
2. Общая справка выводится по `--help` и `-h` в любой позиции, если рядом нет опции со своей справкой
3. Своя справка есть у `-r`/`--retry`/`--re`, `--excluded`, `--login` и `--channel`/`--ch`. Показывается, когда опция
   стоит
   перед `--help`/`-h`: `./run.sh --retry --help`
4. `--channel` переопределяет значение из конфига `search.channel`
    1. Без данной опции канал берётся из конфига
    2. Опция применима как для обычного запуска, так и совместно с опциями `--retry` и `--login`
5. Неверное значение канала — ошибка разбора аргументов до запуска браузера
6. Справка оформляется по [Соглашению об оформлении справки CLI](../../how-to/cli.md): латинские плейсхолдеры в верхнем
   регистре, дефолты в описании, секция `Examples:` в конце
7. `--install-browser` описан одинаково в общей справке и в парсере
8. Пропуск записи чужого канала при повторе пишется только событием `retry_channel_mismatch` в jsonl, без строки в
   консоли

#### Опции и значения:

| Опция                        | Значение                                               |
|------------------------------|--------------------------------------------------------|
| `-h, --help`                 | общая справка или справка опции                        |
| `--install-browser`          | установить Chromium для Playwright                     |
| `--login`                    | войти на сайт выбранного канала и сохранить сессию     |
| `--config <FILE>`            | путь к YAML-конфигурации (по умолчанию: `config.yaml`) |
| `--channel, --ch <CHANNEL>`  | канал запуска, по умолчанию: `search.channel`          |
| `-r, --retry, --re [STATUS]` | повтор по отчётам: [документация](../retry/spec.md)    |
| `--excluded`                 | синоним `--retry excluded`                             |
| `--notify-test`              | тестовое уведомление на email                          |

### Limitations

- Один запуск работает с одним каналом: параллельной обработки двух сайтов нет
- `--install-browser` и `--notify-test` не зависят от канала поиска
- `--no-ops` удалён: обычный цикл и так выполняется по умолчанию, опция ничего не меняла
- Диалогов и интерактивного выбора в CLI нет, кроме ручного входа в браузере

## Acceptance Criteria

- [x] `./run.sh --help` и `./run.sh -h` печатают общую справку со всеми опциями
- [x] `./run.sh --retry --help`, `./run.sh --excluded --help`, `./run.sh --login --help` и
  `./run.sh --channel --help` (а также `--ch -h`) печатают справку своей опции
- [x] В секции `Examples:` есть `./run.sh --channel habr --retry`
- [x] `--channel habr` и `--ch habr` дают одинаковый канал запуска
- [x] `--login --ch habr` открывает career.habr.com и сохраняет сессию Habr
- [x] Без опции канал берётся из `search.channel`
- [x] `--channel superjob` завершается кодом 2, браузер не запускается
- [x] `--install-browser` описан одинаково в общей справке и в парсере
- [x] В консоли нет строки «Повтор пропущен: запись относится к каналу…», событие `retry_channel_mismatch` в jsonl
  сохраняется
- [x] `--no-ops` отсутствует в парсере и в справке
- [x] Ctrl+C — штатная остановка: сессия и отчёт сохраняются, пользователь видит итог без трейсбека.
- [x] Тесты CLI проходят без браузера
