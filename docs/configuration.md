# Настройка

## `.env`

Скопируйте `.env.example` в `.env` — переменные описаны в самом файле:

- `AITUNNEL_API_KEY` — ключ LLM-провайдера (без него запуск не начнётся);
- `SMTP_USERNAME`, `SMTP_PASSWORD` — только если нужны письма на email
  ([notifications.md](notifications.md)).

## `config.yaml`

Единственный источник параметров: поиск и фильтры, лимиты и паузы, LLM, уведомления, пути.
Каждый ключ описан комментарием рядом с ним — отдельного справочника нет, чтобы не держать две версии
правды. Что стоит знать перед первой правкой:

- `search_query` — строка или список запросов; `area` — название региона или числовой id hh.ru;
- `exclude_keywords` — стоп-слова в названии (отсев без LLM), `exclude_companies` — компании-исключения
  (в дневном отчёте получают `status: excluded`);
- `limit_per_run` — сколько откликов за запуск (прежний ключ `daily_limit` тоже принимается);
- `retry.statuses` — какие статусы повторяет (см. `--retry` в [usage.md](usage.md));
- `paths` — профиль, сессия, кэш подъёма резюме, дневные отчёты, логи;
- `llm.decision.criteria` и `llm.decision.threshold` — критерии и порог решения: только здесь,
  в промпте этих значений нет;
- `llm.system_prompt_path` — файл системного промпта (по умолчанию `SYSTEM_PROMPT.md`).

## `data/profile.md`

Профиль для LLM (`paths.profile`): описание, стек и опыт, подраздел «Примеры» с образцами писем
и раздел «Стиль написания сопроводительных писем». Письмо строится только на фактах из профиля:
чего нет в профиле — не должно попасть в письмо.

## `SYSTEM_PROMPT.md`

Правила оценки, стиля, тона и достоверности, формат JSON-ответа. Единственный источник правил:
правки применяются со следующего запуска, код менять не нужно. Если файл удалить, запуск остановится
с понятной ошибкой.
